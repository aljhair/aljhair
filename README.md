## 👨‍💻 Sobre Mí / About Me

¡Hola! Soy **Deyvis**, **Desarrollador de Software** con sólida formación técnica y experiencia práctica en el desarrollo de aplicaciones web, lógica de programación y bases de datos relacionales.

Me especializo en construir soluciones web estructuradas utilizando **PHP bajo el patrón de arquitectura MVC**, conectado a bases de datos **MySQL**, con interfaces dinámicas mediante **HTML5, CSS3 y JavaScript**. Además, utilizo **Python** para el desarrollo de algoritmos, automatización de tareas y manipulación de datos.

Trabajo de forma colaborativa utilizando **Git y GitHub** mediante flujos de trabajo basados en ramas, y aplico la metodología ágil **Scrum** para asegurar entregas organizadas, iterativas y de calidad.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              WORKFLOW & ENGINEERING MINDSET                            │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  💡 Análisis de Requerimientos → 🏛️ Arquitectura MVC → 🗄️ Modelado en MySQL           │
│  → 💻 Código Limpio (PHP / Python / JS) → 🌿 Control de Ramas en Git / GitHub          │
│  → 🧪 Pruebas Locales (Laragon / XAMPP) → 🏃 Entrega por Sprints en Scrum              │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

<div align="center">

| 🎯 Área Clave | 🚀 Habilidades y Enfoque Práctico |
| :--- | :--- |

| **Entornos y Servidores Locales** | Despliegue y pruebas locales con servidores **Laragon y XAMPP**, optimización de flujo en **Visual Studio Code**. |
| **Control de Versiones & Ágil** | Trabajo colaborativo en equipo con ramas en **Git y GitHub**, pull requests y entregables organizados con **Scrum**. |

| **Metodología Ágil Scrum** | Trabajo en equipo organizado por Sprints, estimación de tareas en backlog, reuniones de seguimiento y entregas funcionales incrementales. |
